Microsoft Excel

Spreadsheet software for data organisation, cleaning, and basic analysis

Paid / Free Web Version Windows & Mac 10–15 min install
Why Excel in a DS Course?

Excel is where most business data lives — CSV files, reports, dashboards. As a data scientist, you'll constantly receive data in Excel format and deliver results in it. It's also the fastest way to do quick data exploration without writing code.

Option A — Paid: Microsoft Office / Microsoft 365

Best option if you want the full desktop app. Microsoft 365 is subscription-based but includes Word, PowerPoint, Teams, and 1 TB OneDrive.

  1. Go to the official Microsoft website Open your browser and visit microsoft.com/microsoft-365. Look for "Buy now" or "Try free for 1 month."
  2. Choose your plan Microsoft 365 Personal — ₹4,899/year (1 user, 5 devices). Microsoft 365 Family — ₹6,899/year (up to 6 users). Home & Student 2024 — ₹8,499 one-time (no subscription).
  3. Sign in or create a Microsoft account You'll need a Microsoft account (free to create). Use your email address to register. This account is also used for OneDrive and other Microsoft services.
  4. Complete purchase and go to My Account After payment, visit account.microsoft.com → click "Install Office" → click "Install" button.
  5. Run the downloaded installer Open the downloaded file (named OfficeSetup.exe on Windows). Click Yes when Windows asks for permission. The installer runs automatically — stay connected to the internet.
  6. Wait for installation to complete Takes 10–20 minutes depending on internet speed. You'll see a progress bar. Do not close your laptop or disconnect internet during this step.
  7. Sign in to activate Open Excel from Start menu. Sign in with your Microsoft account when prompted. This activates your licence. You're done!

Option B — Free: Microsoft Excel Online

100% Free — No Installation Needed

If you don't want to pay, use Excel for the web. It has 90% of the features needed for this course.

  1. Visit office.com → Sign in with a free Microsoft account (or create one)
  2. Click Excel from the app list on the left sidebar
  3. Start working — create new workbooks or upload existing .xlsx files directly in browser
✅ How to Verify Excel is Working
  1. Open Excel (from Start menu or search bar)
  2. Click New → Blank Workbook
  3. In cell A1, type: =SUM(10,20) and press Enter
  4. Cell A1 should show 30
  5. If it shows 30 → Excel is installed and working correctly ✅

Anaconda + Python

Installs Python, Jupyter Notebook, and 250+ data science libraries in one package

100% Free Windows / Mac / Linux ~800 MB download Install this BEFORE Python alone
Why Anaconda Instead of Just Python?

Installing Python alone means manually installing every library (pandas, numpy, scikit-learn, matplotlib) one by one. Anaconda installs Python + all 250 essential DS libraries at once, plus Jupyter Notebook. This is what professional data scientists use. Install Anaconda, and you're ready to code immediately.

What You Get with Anaconda: Python 3.11 · Jupyter Notebook · JupyterLab · Pandas · NumPy · Matplotlib · Seaborn · Scikit-learn · SciPy · Conda (package manager) · Anaconda Navigator (graphical launcher)

Step-by-Step Installation — Windows

1
Download the Anaconda Installer

Visit anaconda.com/download. The website automatically detects your OS. Click the big Download button. File name will be like: Anaconda3-2024.xx-Windows-x86_64.exe

2
Run the Installer

Double-click the downloaded .exe file. Windows will ask "Do you want to allow this app to make changes?" → Click Yes. The Anaconda Setup wizard opens.

3
Welcome Screen → Click Next

You'll see the Anaconda3 Setup welcome screen with the Anaconda logo. Click Next to continue.

4
License Agreement → Click "I Agree"

Read the license agreement (scroll to bottom) then click I Agree.

5
Installation Type → Select "Just Me" (Recommended)

Two options: "Just Me" or "All Users". Select "Just Me" — this avoids needing Administrator permissions for every package install later.

6
Choose Install Location → Keep Default

Default path: C:\Users\YourName\anaconda3. Keep this default. Do NOT install in C:\Program Files — causes permission errors. Click Next.

7
⚠️ Advanced Options — CRITICAL STEP

You'll see two checkboxes. Check BOTH boxes:
☑️ "Add Anaconda3 to my PATH environment variable" (important!)
☑️ "Register Anaconda3 as my default Python"
Then click Install. Installation takes 5–15 minutes.

8
Installation Complete → Finish

When you see "Installation Complete!", click Next → you'll see optional "Learn more" checkboxes, uncheck them if you don't want browser windows opening → click Finish.

⚠️ Important After Install

Restart your computer after Anaconda installation before doing anything else. This ensures PATH variables are loaded correctly.

Step-by-Step Installation — macOS

  1. Download the macOS installerVisit anaconda.com/download. Under "macOS", download the Graphical Installer (.pkg) — easier than command line.
  2. Open the .pkg fileDouble-click the downloaded file. macOS may warn "file from internet" → click Open to proceed.
  3. Follow the installer wizardClick Continue through Introduction, Read Me, License (click Agree). For Destination, select "Install for me only".
  4. Complete installationClick Install. Enter your Mac password when prompted. Wait for completion (~10 min). Click Close when done.
  5. Restart TerminalClose and reopen Terminal. You should now see (base) at the start of your prompt — this confirms Anaconda is active.

Launching Jupyter Notebook

After installing Anaconda, you can launch Jupyter two ways:

Method 1 — Anaconda Navigator (Easy)
  1. Search "Anaconda Navigator" in Start menu
  2. Open Anaconda Navigator
  3. Find "Jupyter Notebook" tile → Click Launch
  4. Browser opens automatically at localhost:8888
Method 2 — Command Line (Faster)
  1. Open Anaconda Prompt (Windows) or Terminal (Mac)
  2. Type: jupyter notebook
  3. Press Enter
  4. Browser opens automatically
✅ Verify Python + Anaconda Installation

Open Anaconda Prompt (Windows) or Terminal (Mac/Linux) and run these commands:

Anaconda Prompt / Terminal# Check Python version python --version # Expected: Python 3.11.x or 3.12.x # Check Conda version conda --version # Expected: conda 24.x.x or similar # Check Jupyter is installed jupyter --version # Expected: Shows jupyter_core, notebook versions # List installed packages (you should see 250+) conda list | wc -l

All commands should return version numbers without errors. If you see version numbers = installation successful ✅

Git & GitHub

Version control system + online portfolio for all your code and projects

100% Free Windows / Mac / Linux ~60 MB download
Git vs GitHub — What's the Difference?

Git is software installed on your computer. It tracks every change you make to your code — like "Track Changes" in Word, but for code. You use it through the command line.

GitHub is a website (github.com) where you upload your Git-tracked code. It's your online portfolio — every data science project you build goes here. Recruiters look at your GitHub.

Part 1: Install Git

Windows
macOS
Linux
  1. Download Git for WindowsVisit git-scm.com/downloads → Click "Download for Windows". File is named Git-2.xx.x-64-bit.exe
  2. Run the installerDouble-click the downloaded .exe file → Click Yes for admin permission. Click Next through the first few screens (licence, location) — keep all defaults.
  3. Choose Default EditorYou'll see "Choosing the default editor used by Git". From the dropdown, select "Use Visual Studio Code as Git's default editor" if you have VS Code, otherwise keep Nano. Click Next.
  4. ⚠️ PATH Environment — IMPORTANTSelect "Git from the command line and also from 3rd-party software" (middle option). This lets you use git from any terminal. Click Next.
  5. Keep all remaining defaultsClick Next through: HTTPS transport backend (keep OpenSSL), line endings (keep default), terminal emulator (keep MinTTY), default behaviour (keep default). Click Install.
  6. FinishUncheck "View Release Notes" → Click Finish. Git is now installed.
  1. Check if Git is already installedOpen Terminal and type: git --version. On many Macs, Git comes pre-installed with Xcode Command Line Tools. If you see a version number, you're done!
  2. If not installed — Install via HomebrewFirst install Homebrew: paste this in Terminal: /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
  3. Install GitAfter Homebrew installs, run: brew install git
  4. Alternative: Download installerVisit git-scm.com/download/mac → Download the .dmg installer → Double-click to install.
Terminal# Ubuntu / Debian sudo apt update sudo apt install git # Fedora sudo dnf install git # Arch Linux sudo pacman -S git

Part 2: Create a GitHub Account

  1. Visit github.comGo to github.com → Click "Sign up" (top right corner).
  2. Enter your detailsEmail address → Create a password → Choose a username. Choose your username carefully — this is your professional identity. Use your real name or initials (e.g., priya-sharma-ds).
  3. Verify your emailGitHub sends a verification code to your email. Enter the code on the website. Your account is now active.
  4. Choose the Free planGitHub Free is more than enough for students. It includes unlimited public AND private repositories.

Part 3: Configure Git on Your Computer

After installing Git, run these two commands to link Git to your identity. Open Git Bash (Windows) or Terminal (Mac/Linux):

Git Bash / Terminal — Run Once# Set your name (use your real name) git config --global user.name "Your Full Name" # Set your email (must match your GitHub email) git config --global user.email "your.email@gmail.com" # Verify the settings saved correctly git config --list # Expected: Shows user.name and user.email
✅ Verify Git Installation
Terminalgit --version # Expected: git version 2.xx.x git config user.name # Expected: Your Full Name git config user.email # Expected: your.email@gmail.com
Why GitHub Matters for Your Career

Every project you build in this course should go on GitHub. Recruiters specifically ask for your GitHub link. A GitHub profile with 5 good DS projects is worth more than most certifications.

MySQL

Relational database management system for storing, querying, and managing structured data

100% Free (Community Edition) Windows / Mac / Linux ~500 MB download
What MySQL Is Used For in This Course

You'll use MySQL to write SQL queries — the language used to extract data from databases. SQL is used in every single data analyst role. MySQL Workbench (included in the installer) is the visual interface where you'll write and run those queries.

Installation — Windows (Recommended: MySQL Installer)

  1. Download MySQL Installer Visit dev.mysql.com/downloads/installer. You'll see two options — choose "mysql-installer-community-8.x.x.msi" (the larger file, ~500 MB). Click Download. On the next page, click "No thanks, just start my download" (you don't need to create an account).
  2. Run the installer Double-click the downloaded .msi file. Click Yes for admin permission. The MySQL Installer window opens.
  3. Choose Setup Type → Select "Developer Default" You'll see 5 options. Select "Developer Default" — this installs MySQL Server, MySQL Workbench, and the connection tools all at once. Click Next.
  4. Check Requirements The installer checks for required software. If it shows any items with a yellow warning, click Execute to install missing components. Wait for all to complete, then click Next.
  5. Installation — Click Execute You'll see a list of products to install. Click Execute. Each product installs one by one (takes 5–10 minutes). Wait for all to show green checkmarks, then click Next.
  6. Product Configuration → Click Next Click Next on the Product Configuration screen to start configuring MySQL Server.
  7. High Availability → Keep "Standalone MySQL Server" (default) Select Standalone MySQL Server / Classic MySQL Replication (default). Click Next.
  8. Type and Networking → Keep all defaults Config Type: Development Computer. Port: 3306 (default). TCP/IP: checked. Click Next.
  9. Authentication Method → Keep "Use Strong Password Encryption" Keep the default option selected. Click Next.
  10. ⚠️ Set Root Password — WRITE THIS DOWN You must create a password for the root (admin) user. Write this password down immediately — you cannot recover it if forgotten. Use something memorable: e.g., DataScience@123. Enter it twice, then click Next.
  11. Windows Service → Keep defaults MySQL will run as a Windows Service. Keep "Start the MySQL Server at System Startup" checked. Click Next.
  12. Apply Configuration → Execute Click Execute. MySQL Server is now being configured. All 5 steps should get green checkmarks. Click Finish.
  13. Complete Remaining Configuration Steps Click Next → Finish through any remaining screens (MySQL Router, Samples). On the last screen, keep "Start MySQL Workbench after setup" checked → Click Finish.

First Login to MySQL Workbench

1
MySQL Workbench opens automatically

You'll see the Workbench home screen with a connection box labeled "Local instance MySQL80" with port 3306.

2
Click the connection box to connect

A dialog asks for the password. Enter the root password you created during installation. Check "Save password in vault" so you don't need to type it every time. Click OK.

3
You're in!

MySQL Workbench opens showing the query editor. The left panel shows databases. You're connected and ready to write SQL.

✅ Verify MySQL Installation

In MySQL Workbench, click the Query tab and type:

MySQL Workbench Query-- Type this and press Ctrl+Enter (or click the lightning bolt) SELECT VERSION(); -- Expected output: 8.x.xx (a version number) SHOW DATABASES; -- Expected: Shows information_schema, mysql, performance_schema, sys

If you see MySQL version number and database list = successfully installed ✅

Microsoft Power BI Desktop

Free business analytics tool for building interactive reports and dashboards from any data source

100% Free Windows Only ~500 MB download No Mac version
Important: Windows Only

Power BI Desktop is available only for Windows. Mac users can use Power BI Service (the browser version at app.powerbi.com) which requires a free work/school email (not Gmail). For Mac students, Tableau is the alternative desktop tool.

What You'll Build with Power BI

Connect to Excel, CSV, databases, and web sources → Clean and transform data → Build interactive charts, maps, and KPI cards → Combine into dashboards → Publish to share with teams. Power BI is the #1 BI tool used in Indian enterprises today.

Installation — Method 1: Microsoft Store (Easiest)

  1. Open Microsoft StorePress Windows key → search "Microsoft Store" → Open it.
  2. Search for Power BIIn the Store search bar, type "Power BI Desktop" and press Enter.
  3. Click "Get" or "Install"Click the Get button. You may need to sign in with a Microsoft account. The download and installation happen automatically.
  4. Launch from Start MenuAfter installation, search "Power BI Desktop" in the Start menu. Click to open.

Installation — Method 2: Direct Download (If Store Doesn't Work)

  1. Visit the Power BI download pageGo to powerbi.microsoft.com/downloads. Click the "Download free" button under "Power BI Desktop".
  2. Choose your language and downloadSelect English from the language dropdown. Choose 64-bit (recommended for all modern computers). Click Download.
  3. Run the installerOpen the downloaded PBIDesktopSetup_x64.exe. Click Next on the welcome screen.
  4. Accept License AgreementCheck "I accept the terms in the License Agreement" → Click Next.
  5. Choose destination folderKeep the default folder: C:\Program Files\Microsoft Power BI Desktop. Click Next → Click Install.
  6. Installation completesTakes 2–5 minutes. When done, click Finish. Power BI Desktop opens automatically.

First Launch Setup

1
Welcome screen appears

Power BI shows a "Welcome to Power BI Desktop" screen with options to connect to data, open a recent file, or take a guided tour. Close this dialog for now.

2
Sign in (Optional but Recommended)

Click Sign in in the top right. Use a Microsoft account (work/school email preferred). Signing in enables publishing reports to Power BI Service for sharing. Personal Gmail will NOT work — use Outlook or your institute email.

3
Quick Test — Connect to Excel Data

Click Get Data → Excel Workbook → select any .xlsx file on your computer → click Load. If a table appears on the right panel, Power BI is fully working.

✅ Verify Power BI is Working
  1. Open Power BI Desktop
  2. Click Home → Enter Data
  3. Type some numbers in the table that appears → Click Load
  4. On the right side, you should see a "Fields" panel with your data
  5. Drag a number field to the canvas — a chart should appear
  6. If chart appears = Power BI working correctly ✅

Tableau Desktop

Industry-leading data visualisation tool for creating interactive, publication-quality dashboards

Free for Students (1 year) Windows & Mac ~1 GB download
Student Licence — 1 Year Free

Tableau offers a free 1-year student licence for enrolled students. This gives you the full Tableau Desktop (normally ₹75,000/year) for free. Use your college/institute email to verify student status. This is the recommended option — do this before the 14-day trial.

Student licence URL: tableau.com/academic/students

Option A — Student Licence (Recommended)

  1. Visit the Student Licence pageGo to tableau.com/academic/students. Click "Get Tableau for Free".
  2. Fill in the verification formEnter: First name, Last name, College/university email address (.ac.in or .edu email), School name, Country (India), Graduation year. Click Verify Student Status.
  3. Confirmation email arrivesCheck your college email inbox. Tableau sends a confirmation link. Click "Confirm and Download". This takes you to the Tableau download page.
  4. Download Tableau DesktopOn the download page, click Download Tableau Desktop. Choose Windows (.exe) or macOS (.dmg) based on your system.
  5. Install TableauRun the installer. Follow the wizard — accept licence, choose installation folder (keep default). Takes 5–10 minutes.
  6. Activate with Student Licence KeyWhen Tableau opens, select "Activate Tableau". Enter the licence key from the email Tableau sent you. Click Activate. You're done — full access for 1 year!

Option B — 14-Day Free Trial

If you don't have a college email or are a career switcher, use the 14-day trial to get started:

  1. Visit Tableau products pageGo to tableau.com/products/desktop. Click "Try for Free".
  2. Fill in your detailsEnter your name, work email, company/organisation name, country. Click "Download Free Trial".
  3. Download and installSame installation steps as Option A above (Steps 4–5). Run the installer, follow the wizard.
  4. Sign in on first launchWhen Tableau opens, click "Start Trial" → Sign in with the email you used to register. Trial starts from this moment — you have 14 days of full access.
⚠️ Trial Timing Tip: Don't start the 14-day trial until your Tableau session in class begins. Register and download now, but only activate (click "Start Trial") when the instructor says it's time to use Tableau in lessons. This maximises your 14 free days.
